About this comparison

These are three supplied SDR exports of the same scene, illustrating the differences described here. Their overall color and exposure differ; this is a comparison of these renders, not every possible setting in each app.

Darkroom’s 6000 × 4000 export is displayed at the same framing as Dark Melon’s 3000 × 2000 image. Alternative 2’s 3000 × 2004 export receives a small scale and position correction for alignment. Original JPEGs are preserved; the viewer applies no color or brightness adjustments.
